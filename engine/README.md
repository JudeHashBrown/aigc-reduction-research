# 诊断引擎 v0.1

纯代码、零 LLM、可复现。同一段文本跑两次结果必然一致。

```bash
python3 engine/cli.py samples/ai_sample.txt        # 人读报告
python3 engine/cli.py samples/ai_sample.txt --json # 结构化输出，给前端
```

## 模块

| 文件 | 职责 |
|---|---|
| `lexicon.py` | 中文 AI 高频词表，T1/T2/T3 三级共 140 条 |
| `patterns.py` | 16 条句式/段落/格式规则 + 6 条硬约束 |
| `metrics.py` | 统计指标：句长变异、实词密度、**具体性（数字/专名密度）**、TTR、4-gram 自相似 |
| `diagnose.py` | 主流程，输出逐句归因 |
| `cli.py` | 命令行报告 |

## 对照实验（v0.1）

同题材、同长度（约 450 字）的 AI 稿与人写稿：

| | AI 稿 | 人写稿 |
|---|---|---|
| 检出特征 | **19**（🔴12 🟡7） | **1**（🟢1） |
| 高风险段落 | 3 / 4 | 0 / 4 |
| 硬约束违反 | 5 | 0 |
| 数字密度（每百字） | **0.0** | **3.97** |
| 专名密度（每百字） | **0.69** | **2.87** |
| 句长变异系数 | 0.36 | 0.54 |

具体性两项指标的分离最干净，与「回归均值导致具体事实被抹除」的理论判断一致。

## 关于阈值

**规则层可信**（命中即可核对原文），**统计层阈值未标定**。
`metrics.CALIBRATED` 控制哪些指标允许告警，默认只有 `digit_density`。
其余阈值抄自 AIGC-Detector-Pro（无出处），待黑盒探测标定后整体替换 —— 
在那之前不拿它们告警，否则和竞品编造百分比没有区别。

# 第二层：LLM 改写

```
原文 → ① codefix（纯代码） → ② rewrite（LLM best-of-N） → ③ codefix 后处理 → 诊断
```

第三步再跑一遍代码是刻意的：**让最后碰文本的是确定性代码**，把 LLM 可能带回来的套话清掉。

## 两层的分界

| | 代码层 | LLM 层 |
|---|---|---|
| 中文 | V-T1/T2、S03、S04、S05、S07、S08、P02、F01、F02 | S01、S02、S06、S09、S10、P01 |
| 英文 | V-T1/T2、S04、S05、S07、S08、P02、F01 | S01、S02、S03、S09、S11、S12、P03 |

分界依据是**能不能在不理解语义的前提下改对**。
`S01 三元并列`两种语言都归 LLM——代码修法是删掉第三项，那是信息丢失。

## 四条约束

1. **定向**：只改被标记且代码修不了的段落。作者原本写对的句子是最好的资产，
   每过一次 LLM 就被注入一次 AI 统计特征。
2. **验证**：改完重新诊断，用诊断分数做 best-of-N 选优。没有改进的候选直接丢弃。
3. **事实护栏**（`guard.py`）：机械比对改写前后的数字、专名、引用。
   **新增任何一项即判废。**五份资料全都只在提示词里写「不要编造」，
   而其中两份的示例本身就在编造——提示词约束不可靠，必须用代码卡死。
4. **噪声预算**：目标不是清零。孤立的低危特征（破折号等）按每千字 3 处的预算保留。

## 替换优先原则（中英通用）

删除只对「可有可无的套话」安全。承载语义的词必须替换：

- 英文：删掉动词或分词直接断句 →「framework **is a tool, performance** across…」
- 中文：删掉谓语核心同样出事 →「该技术在临床诊断中**很。**」

所以两种语言都是：有替换词就替换，无替换词且不在 `DELETABLE` 白名单里就**保持原样**。
**语法错误本身就是另一种可检测的异常，比原来的 AI 味更糟。**

## 实测

| 样本 | 原文 | ① 代码 | ② LLM | 文本是否被改 |
|---|---|---|---|---|
| AI 稿（中文） | 20 | 5 | 0 | 是 |
| AI 稿（中英混排） | 27 | 0 | — | 是 |
| **人写对照** | **1** | **1** | **1** | **否（一个字符都没动）** |

最后一行最重要：定向干预不是口号，人写的文本过完整流水线**零改动**。

## 配置 LLM

```bash
export LLM_BASE_URL=https://api.openai.com/v1   # 或任何 OpenAI 兼容端点
export LLM_API_KEY=sk-...
export LLM_MODEL=gpt-4o-mini                     # 可选
export LLM_TEMPERATURE=0.85                      # 可选，默认 0.85
python3 web/server.py
```

温度默认偏高是刻意的：降 AI 率需要输出有变化。
BypassAIGC 用 `reasoning=high` 且不传 temperature，输出更收敛——方向是反的。

未配置时改写层自动禁用，规则层照常可用。
