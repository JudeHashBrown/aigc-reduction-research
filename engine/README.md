# 诊断引擎 v0.1

纯代码、零 LLM、可复现。同一段文本跑两次结果必然一致。

```bash
python3 engine/cli.py samples/ai_sample.txt        # 人读报告
python3 engine/cli.py samples/ai_sample.txt --json # 结构化输出，给前端
```

## 模块

| 文件 | 职责 |
|---|---|
| `lexicon.py` | 中文 AI 高频词表，T1/T2/T3 三级共 140 条 |
| `patterns.py` | 16 条句式/段落/格式规则 + 6 条硬约束 |
| `metrics.py` | 统计指标：句长变异、实词密度、**具体性（数字/专名密度）**、TTR、4-gram 自相似 |
| `diagnose.py` | 主流程，输出逐句归因 |
| `cli.py` | 命令行报告 |

## 对照实验（v0.1）

同题材、同长度（约 450 字）的 AI 稿与人写稿：

| | AI 稿 | 人写稿 |
|---|---|---|
| 检出特征 | **19**（🔴12 🟡7） | **1**（🟢1） |
| 高风险段落 | 3 / 4 | 0 / 4 |
| 硬约束违反 | 5 | 0 |
| 数字密度（每百字） | **0.0** | **3.97** |
| 专名密度（每百字） | **0.69** | **2.87** |
| 句长变异系数 | 0.36 | 0.54 |

具体性两项指标的分离最干净，与「回归均值导致具体事实被抹除」的理论判断一致。

## 关于阈值

**规则层可信**（命中即可核对原文），**统计层阈值未标定**。
`metrics.CALIBRATED` 控制哪些指标允许告警，默认只有 `digit_density`。
其余阈值抄自 AIGC-Detector-Pro（无出处），待黑盒探测标定后整体替换 —— 
在那之前不拿它们告警，否则和竞品编造百分比没有区别。
