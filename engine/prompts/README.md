# 外部提示词

## humanizer_zh.md

取自 humanizer-zh-academic 的 `SKILL_full.md`（去掉 frontmatter）。
许可证开头：`MIT License`

**这份提示词与本引擎的信息守恒原则直接冲突。**
它的「注入学者个性」一节明确要求加入原文没有的内容：
承认局限、表达意外、留下判断（示例：「出乎意料的是，访谈中没有一位受访者提到……」）。
那是编造，`engine/guard.py` 会判废。

因此接入时分两种模式：
- `humanizer`        —— 完整执行，**关闭编造守卫**。仅供实验，不可用于用户真实论文。
- `humanizer-safe`   —— 执行其余部分，保留守卫，跳过一切需要凭空添加内容的做法。

它 README 宣称「AIGC 检测率 >50% → 11%」，未给检测器名称、样本量与方法。
本项目在腾讯朱雀上的实测是：任何 LLM 改写（含改动 59% 字数的激进改写）
都维持 100%。两个结果冲突，以可复现的那个为准。
